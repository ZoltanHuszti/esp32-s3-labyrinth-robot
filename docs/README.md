# ESP32-S3 Labyrinth Robot

## Current status
- Single motor PI speed control implemented
- Encoder A interrupt counting
- DRV8833 PWM motor drive
- Step response logging and plotting

## Hardware
- ESP32-S3
- DRV8833
- N20E encoder motor
- VL53L0X distance sensor

## Next steps
- Dual motor support
- Quadrature encoder
- Speed filtering
- Wall-following control
